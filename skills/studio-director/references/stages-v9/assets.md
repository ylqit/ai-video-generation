# 资产与声音身份

新结果填写 contractRevision:2。逐个检查导演 interactions 中 required=true 的关键物理互动，安排 coverage=[{shotId, interactionIds, aspects}]，interactionIds 精确指向本镜交互，aspects 可含 identity/space/prop/interaction/composition/style/boundary。同图可覆盖兼容机位；组首帧不自动代表组内后镜。身份与当前外观图不能承担交互覆盖，必要时为同图另声明明确的构图用途。无法覆盖时保持缺口，不能通过删掉关键交互或增加额度掩盖。

每项图片填写 preserve 和 allow 的纯画面要求。身份图保留辨识特征，允许镜头改变朝向、目光、姿态、背景与构图；环境图只保持确定的结构与外观。description 供人阅读制作需求，prompt 用于图片制作，二者不直接成为视频执行正文。视频仅消费确认过的 preserve/allow；不加入后段动作、政策、额度或审批。故事板和带标记的灰模用于制作审查；只有明确的干净单帧构图才申请首帧约束。

依据已采用剧本和导演计划，只制作会被引用且需要稳定身份、空间或声音的资产。实际图片、音频未提供时输出需求，不捏造 Resource ID 或已生成状态。完全没有需要独立引用的资产时 items 可为空。

每项对应已声明 subjectKey 和真实 shotIds，明确唯一主要用途。身份、当前外观、环境、构图、动作起止、画风和声音不能混为同一个默认条件。图片只描述一个时点的姿态、受力、视线与画面；连续情绪的起伏与错峰过程交给视频导演。

layout 根据主体、用途和输入模式选择：真人可以用身份与全身视图，动物用能辨识体型的视图，产品保留完整几何和品牌原件，场景保留必要空间锚点。不强制4:3或人像双栏，不重绘Logo后冒充权威资料。保持稳定设计与动态状态分离。

声音身份使用 mediaType=audio、purpose=voice。文字音质不是已绑定音色；当前能力不支持音频条件时写明限制，不能自动忽略声音身份。视觉项的 prompt 是完整静帧请求，音色项为准确需求；生成、导入、审核和确认由系统与项目策略处理。


## 图片准备方法修订 9.3

prompt 必须完整表达当前静帧的主体、已确认视觉方向及当前用途，不依赖执行阶段再附加整段美术规范。只选择本镜需要的稳定条目；身份描述不混入后续动作、暂时持物或未出场人物。参考图本身可能带有不适用背景、人物或未来状态，文字“只参考身份”不保证清除这些内容；需要时提出裁剪、编辑或重新准备，实际审图前保持待确认。

先查询已有固定素材再提补全需求。仅为当前任务必需或能明确复用的视图安排制作；普通产品、动物和空镜不要求人体三视图。复合图板仍是一张输入，无法自动提供独立多角度条件。未知运动参考能力不得假设支持，抽帧只能成为静态用途。
