# Studio 创作工作台

Studio 把完整创作方案、执行范围、真实素材和候选审看放在同一作品中。支持短片与系列项目，使用 Vue、Express、SQLite、Codex CLI、原 Worker、ComfyUI/H3 和 FFmpeg。

## 使用

- **项目**：打开作品，在资源画布、分镜与时间线之间切换。右侧助手支持讨论、明确范围的修订和执行。
- **素材库**：默认显示参考与视频候选；按用途和媒体类型在服务端筛选后分页。原音、尾帧和问题证据归属候选，审看导出也可独立筛选。
- **任务**：查看实际任务状态、回执、归档与错误。已受理和受理不明的任务不重复派发。
- **设置**：设置推进方式、时长意图、演绎权限、额度与执行通道。

先保存完整需求、剧本、方向和导演计划，再选择全片或局部执行范围。缺少范围外图片不阻止当前范围的准备。创作保存、生成提交、实际媒体审核和最终确认拥有不同边界。

保存范围时可展开“执行文案”，对照中文原文填写并核对英文生成描述。它固定在本次范围中，原故事、日语等原始对白、镜头时长和出场安排保持原版本。预览不会自动翻译；原文变化后需要重新核对对应文案。

图片由标准 Codex 素材任务交接：在素材需求选择“交给 Codex 制作”，复制指令或下载任务资料，在可用图像工具的 Codex 会话执行，再通过交付接口回填。后台文字 Runner 不承担图片生成。回填候选需要实际审看后绑定用途。

H3 视频候选与提取的原音直接预览。候选可以进入审看编辑，裁剪、排序、拆分、加入导入音频、编辑中文字幕并导出审看版。审看导出不会自动采用媒体。正式装配只使用已采用素材，最终确认指向实际导出版本。没有完整视觉或听审证据时继续显示待审。

时间线中的“样片与整片交付”可分别创建范围样片和完整作品，每份计划拥有独立时间线与导出版本。保存音量、音轨、字幕或时长调整会形成新版本，必须重新导出、观看和确认。12 秒样片确认不会把 60 秒作品标为完成。无法由实际逐镜采用区间可靠映射的声音和字幕先进入校对清单。

时间线的“创作版本”选择同一分集的 V9 运行。独立草稿完成前置阶段和本次参考确认后，可显式激活为当前制作版本；切换使用版本检查，活动或待归档作业阻止切换。参考需求支持批量审看/听审、填写实际结论后同时确认绑定。

人物、场景与镜头卡直接打开固定版本的对象阅读详情；编辑单独进入表单。缺少分项表演或接续状态时明确显示尚未填写，不补造剧情。镜头声音、对白、状态和引用在阅读与编辑中均可定位。

普通预览不创建素材。新视频归档保留真实原片和原音；尾帧和证据只在明确操作时提取，同源同帧复用。素材库“清理中间文件”先核对历史引用、独立备份与哈希，再清理未被使用的抽帧；从“已清理记录”显式恢复。清理和恢复不修改资产版本、原任务回执或审核结论。

详见 [工作台使用](docs/WORKSPACE_GUIDE.md)、[架构与边界](docs/ARCHITECTURE.md)、[接口](docs/API.md)。

## 启动与验证

Node.js >=24，系统可用 FFmpeg/FFprobe。安装依赖后：

```powershell
npm run typecheck
npm test
npm run build
npm start
```

生产服务默认 `http://127.0.0.1:4310`。`npm run dev` 同时启动 API、Worker 和 Vite（4311）。仅验证页面时单独启动 API，不启动 Worker；用 `STUDIO_DATA_DIR` 指向隔离数据、`STUDIO_PORT` 指定独立端口。

`npm run doctor` 检查本地依赖；`npm run doctor -- --cloud` 只读核对远端能力。测试使用临时 SQLite、模拟模型响应与本机合成媒体，不调用真实模型。

```powershell
npm run backup -- <备份目录>
npm run backup -- restore <备份目录> <新的空数据目录>
npm run retain:workspace -- <已备份数据目录> <新的空数据目录> <保留项目ID>
```

数据备份和保留工具只用于当前 V9 数据的维护，目标必须为空。完整切换还须备份运行程序、任务目录和配置；旧库的恢复由匹配的离线程序负责。

当前唯一专业作者协议为 schemaVersion 9，数据库为 v4。空库直接建立 v4；旧版本数据库或含旧作者记录的 v4 库均拒绝启动，不提供 V8 展示、升级、阶段注入或旧候选关联入口。H3 模板、系列事实和媒体证据的版本仍是各自的业务契约。

生产切换前停止 API/Worker，处理活动、受理不明与待归档作业，完整备份匹配的程序、数据库、任务、媒体版本及恢复字节并核验哈希。旧项目留在活动目录之外。回退需同时使用匹配的旧程序与完整数据库备份，先另存切换后新增数据，禁止只退程序继续写新库。
