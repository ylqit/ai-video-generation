# Studio 制作节点与自由创作工作台

Studio 将作品、文档、素材、生成节点、Agent 和剪辑放在同一个版本化工作区。使用 Vue、Express、SQLite、原 jobs／Worker 与 FFmpeg。单部试作、单集、5 分钟 × 10 集和多系列共用同一数据体系，集数与时长可调整。

本轮改变了业务规则：**未审核素材可直接使用，未审核时间线可导出，前集未交付也可依据剧本继续创作。** 质量观察可选；选用与定稿不代表系统确认质量通过。实际模型协议、文件范围、任务归属、并发版本、额度和重复提交仍在执行时检查。

**最新交互增量（2026-11-24）：** [B0—B6 工作台 SDD](specs/workbench-interaction/README.md) 已完成。多节点与具体候选引用、统一导入、节点播放器与制作托盘、v4 持续助手、交互 EDL 时间线已接入；[370 项回归和 10 条浏览器验收](specs/workbench-interaction/VERIFICATION.md)通过。本轮仅模拟供应商与合成媒体，真实请求为零。

## 使用路径

- **作品**：新建空白画布、从创意起步或导入文字。画布、文档、分镜与候选、剪辑共享实际对象。系列计划在作品结构内打开；人物、镜头、导演及序列使用专属节点和编辑器。
- **画布**：18 类内容、素材、生成、处理和组织节点；类型化输入端口、明确参考顺序与用途、固定版本。支持多选、复制、分组、整理、搜索、撤销／重做、视口和草稿恢复。组织连线不成为模型输入。任务自动回填候选，抽帧、截取、拉片及选用不要求跳到其他页面。
- **Agent**：画布内独立浮窗，可移动、缩放、停靠、最小化。先讨论或引用节点，再明确制作目标、范围、允许动作、模型及用量。默认 20 次决策；范围内连续执行，无逐次质量审批。会话与运行分开保存，等待由真实任务事件推进。
- **加工与理解**：图片裁剪／标记／拆图，本地视频／音频处理、切镜与关键帧；可选 Chat 采样图分析和腾讯极速转写。图片重绘／打光／多角度／全景使用固定编辑计划，明确为模型请求。分析不等于整片质量判断。
- **导演预演**：基础人物／几何体代理、相机、焦距、灯光和关键帧；本地离屏 PNG／MP4，关闭画布后仍可完成。预演素材明确标记，不能作为真实表演证据。
- **剪辑**：直接添加真实媒体，编辑裁剪、音量、独立音轨、字幕、淡入淡出和叠化。实际时长与目标分别展示；不为凑时长自动伸缩或补画面。导出固定 EDL 和媒体版本，定稿不自动产生质量评价或剧情事实。
- **素材库**：按类型和作品查找真实媒体；全局音色独立分类，目录移动不改变作品固定选用的版本。媒体预览不调用模型。
- **任务**：查看执行阶段、等待原因、结果和回到画布入口。未观察不属于任务异常；归档失败、受理不明和版本变化有独立处理。
- **设置**：文本／图片／视频／语音分类；模型家族与连接协议分开。连接全局管理，作品及任务固定自己的选择。配置与启用不产生生成请求。

完整改动、责任边界和操作接口见 [制作节点实施](../docs/architecture/2026-11-23-node-workbench/IMPLEMENTATION.md)，[Toonflow 源码取舍](../docs/architecture/2026-11-23-node-workbench/SOURCES_AND_MAPPING.md) 和 [分项验收](../docs/architecture/2026-11-23-node-workbench/VALIDATION.md)。两张概览、八类页面和可点击原型位于 `/design/node-workbench/index.html`，原型只使用模拟数据。自由创作的业务规则沿用 [前次实施](../docs/architecture/2026-11-23-free-creation/IMPLEMENTATION.md)。

## 执行与资料边界

画布助手调用原业务服务，不直接运行脚本或建立第二套队列。每次操作保存意图、幂等标识和回执；媒体由原 Worker 上传、提交、恢复和归档。上传或准备期间暂停，会在付费提交前再次检查状态；已受理任务继续归档，受理不明核对原任务。用户同时编辑时，旧 Agent 决策不会覆盖新内容。

当前剧本与人物设定属于剧情依据，实际选用区间和用户观察属于媒体依据。视频偏离剧本不会自动改写剧情。无媒体理解能力时，Agent 不声称已经看完视频或听过音频，不凭想象质量问题反复生成。

确定性预览不上传、不生成、不隐式翻译或改写。当前新画布使用 `canvas-h3-v2`／`canvas-seedance-v2`／`canvas-image-v2`，复用专业镜头的内容投影与导演表达；旧模板和冻结任务保持原义。布局变动不使准备过期，实际内容或固定输入变化才需重新准备。H3 官方 API 的视频／音频参考不外推到其他接入协议。

专业资料继续支持来源索引、整季提案、主体映射、剧本、导演和局部修订，由作品结构和对象编辑器访问。可选检查填写时仍校验来源与证据，不能把未观察写成通过。新音频／口型试作可以从空白画布直接引用真实素材，不需虚构分集。

模型及声音接入详见 [模型平台](docs/MODEL_PLATFORM.md)、[声音生产](docs/VOICE_PRODUCTION.md)。这些适配没有因本轮 UI 与流程重构获得新的真实质量验证。全域清单从 [功能研究罗盘](../docs/COMPASS.md) 进入；旧文档中的强制批准、强制听审及审核后交付要求已由本轮方案替代。

## 启动与验证

Node.js >=24，系统可用 FFmpeg／FFprobe：

```powershell
npm run typecheck
npm test
npm run build
npm start
```

默认生产服务 `http://127.0.0.1:4310`。`npm run dev` 会同时启动 API、Worker 和 Vite（4311）；仅验证页面时不要启动生产 Worker。用 `STUDIO_DATA_DIR` 指定隔离数据、`STUDIO_PORT` 指定独立 API 端口。

本轮提供完全隔离的演练服务：

```powershell
# 新建隔离库，或传入 .artifacts/node-workbench-demo-* 目录恢复本轮演练
node --import tsx scripts/node-workbench-demo.ts
# 另一终端，仅启动页面
$env:STUDIO_API_ORIGIN = 'http://127.0.0.1:4393'
npx vite --host 127.0.0.1 --port 4394
```

演练使用原 API、原 Worker 和真实 FFmpeg，但拦截文字／视频模型为本机模拟，并拒绝其他外部供应商请求。生成内容为测试图和合成声音，不是模型画质验证。真实供应商要在正式连接与额度中另行选择。

`npm run doctor` 检查本地依赖；`npm run doctor -- --cloud` 只读核对远端能力。测试使用临时 SQLite、模拟模型响应和合成媒体。

## 数据与迁移

当前数据库 v6，专业作者 V9 修订 2；新画布 v2、助手运行 v3、剧情 Canon v4 分别版本化。旧 v4／v5 库仍需先按模型和声音文档显式升级。v1 画布在进入后显示转换预览，显式应用后使用新节点操作。新建作品直接使用 v2。转换使用原 documents，不新增 SQL 版本，不重写真实任务输入。

```powershell
npm run backup -- <备份目录>
npm run backup -- restore <备份目录> <新的空数据目录>
# 停止目标目录 API / Worker 后预览，不写数据
npm run migrate:free-creation -- <数据目录>
# 自动完整备份并校验预览摘要，增量创建画布与来源映射
npm run migrate:free-creation -- <数据目录> --apply
```

迁移暂停旧助手并保留历史记录、媒体、审核、远端回执及旧 EDL。排队和已受理任务不重编译；活跃租约或并发变化会拒绝迁移。当前生产库未迁移，本轮真实付费请求为零。回退使用匹配程序与完整备份，先保留切换后新增数据，不直接覆盖。
